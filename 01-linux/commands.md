# Linux Commands Practical

## Objective
To understand basic Linux commands and shell scripting.

## Commands Practised

| Command | Purpose |
|---|---|
| `pwd` | Displays the current working directory |
| `ls -la` | Lists files, including hidden files |
| `mkdir` | Creates directories |
| `cd` | Changes the current directory |
| `touch` | Creates an empty file |
| `cat` | Displays or creates file content |
| `cp` | Copies files |
| `mv` | Moves or renames files |
| `chmod +x` | Makes a script executable |
| `du -sh` | Displays the total size of a file or directory |
